# Aashapura Rasoi — Website

A mobile-first promotional website for Aashapura Rasoi, a homemade Gujarati food
and tiffin business based in Mira Road East, Mumbai, Maharashtra, India.

## Development

```bash
npm install
npm run dev
```

The local development server starts at **http://localhost:5173**
